🛒 Simple Shopping Cart

تطبيق عربة تسوق بسيط تم تطويره باستخدام Next.js وReact، يتيح للمستخدم استعراض مجموعة من المنتجات وإضافتها إلى سلة التسوق، مع إمكانية حذف المنتجات أو تنظيف السلة بالكامل وحساب إجمالي السعر بشكل تلقائي.

📌 وصف المشروع

مشروع تدريبي يهدف إلى تطبيق مفاهيم React State Management والتعامل مع بيانات المنتجات وتنفيذ العمليات الأساسية على سلة التسوق.

يحتوي التطبيق على قائمة بالمنتجات، ويمكن للمستخدم:

عرض المنتجات المتاحة.
إضافة أي منتج إلى سلة التسوق.
حذف منتج من السلة.
تنظيف السلة بالكامل بضغطة واحدة.
حساب إجمالي أسعار المنتجات الموجودة في السلة تلقائيًا.
تحديث البيانات مباشرة عند إجراء أي عملية.

🎯 الوظائف الأساسية
إضافة منتج

يمكن للمستخدم الضغط على زر الإضافة لإضافة المنتج إلى سلة التسوق.

حذف منتج

يمكن للمستخدم حذف أي منتج من السلة بشكل منفصل.

تنظيف السلة بالكامل

يمكن للمستخدم الضغط على زر Clear Cart لإزالة جميع المنتجات من السلة وإعادتها إلى حالة فارغة.

حساب الإجمالي

يتم حساب إجمالي أسعار المنتجات الموجودة في السلة باستخدام reduce()، ويتم تحديث الإجمالي تلقائيًا عند إضافة أو حذف المنتجات أو تنظيف السلة بالكامل.
